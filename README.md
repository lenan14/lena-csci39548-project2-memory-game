# lena-csci39548-project2-memory-game

## Memory Game

### What We Started With

I started with the provided starter code and built on it by adding features I thought would be cool for this memory game. I also updated the styling to match my preferences and make it more appealing to look at as I play!

### What I Added

- A timer and an attempts counter
- A message that appears when all the card pairs are matched (In other words, when the user wins!)
- Purple and blue styling for the page and cards, since those are my favorite colors

### How I Added It

Using what I know and what we've learned so far in the course, I updated the game to track the time, attempts, and when the player wins. The timer starts when the first card is picked and stops when the game is won. I also changed the CSS to style the page and cards in purple and blue!
